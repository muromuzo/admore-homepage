# 애드모어 ADMORE 홈페이지

퍼포먼스 마케팅 · 광고 대행사 **애드모어(ADMORE)** 공식 홈페이지 정적 사이트.

## 구성

```
index.html          # 원페이지 랜딩 (스타일·스크립트 인라인)
assets/
  admore-h.png      # 가로형 로고
  admore-stack.png  # 스택형 로고
```

## 로컬 확인

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 배포

`main` 브랜치 푸시 시 GitHub Pages로 자동 배포됩니다.
